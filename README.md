## 1. Overview
This is a Hydration Reminder mobile application built with React Native and Expo. The app demonstrates the implementation of local notifications and a multi-tab navigation layout using Expo Router.

## 2. What We Built
- A 3-tab application (Reminder, Tips, About) using Expo Router.
- A custom Notification Handler to show alerts while the app is in the foreground.
- Requesting OS-level Notification permissions.
- Scheduling and cancelling repeating notifications using `TIME_INTERVAL`.
- Static educational screens (Tips and About).

## 3. Key Features
- **Custom Reminders:** Users can set a custom message and a time interval (in minutes).
- **Start/Stop:** Users can start the reminder cycle and stop it at any time.
- **Live Status:** The UI updates to show whether the reminder is currently active or inactive.

## 4. How to Run
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npx expo start -c` to start the development server (with cache cleared).
4. Scan the QR code using the Expo Go app on a physical device.
